# Mythic Game Master Emulator 2e - Quick Reference

## The Fate Chart (Oracle)

Use this to answer yes/no questions when the outcome is uncertain.

### Chaos Factor
- Starts at 5 (range 1-9)
- Increases when scenes go out of control
- Decreases when players are in control
- Higher chaos = more likely "yes" and more random events

### Odds and Target Numbers
Roll d100 against these thresholds based on the odds of "yes":

### Interpreting Results
- Roll ≤ threshold: **YES**
- Roll > threshold: **NO**
- Roll ≤ (threshold / 5): **EXCEPTIONAL YES** (emphatic positive)
- Roll > 100 - (threshold / 5): **EXCEPTIONAL NO** (emphatic negative)
- Doubles (11, 22, 33, etc.) AND roll ≤ chaos factor × 11: **RANDOM EVENT**

## Random Events

| Roll | Focus |
|------|-------|

| 8-28 | NPC Action (an NPC does something) |
| 29-35 | Introduce a New NPC |
| 36-45 | Move Toward a Thread (advance a plot) |
| 46-52 | Move Away from a Thread (complicate a plot) |

## Scene Setup

At the start of each scene:
1. Set the expected scene
2. Roll d10 vs Chaos Factor
   - Roll ≤ CF on odd: **Scene is altered** (something different happens)
   - Roll ≤ CF on even: **Scene is interrupted** (something completely different)
   - Roll > CF: Scene proceeds as expected

### Altered Scene
Keep the same basic setup but change a significant detail.

### Interrupted Scene
Roll a random event - this replaces the expected scene entirely.

## Threads and NPCs

### Thread List
Track ongoing plot threads. Each scene should involve at least one thread.

### NPC List
Track NPCs. When random events involve NPCs, randomly select from this list.

## Complex Questions

For questions beyond yes/no, use the **Detail Check**:
- Roll on Event Meaning tables (Action + Subject)
- Interpret the combination creatively

## Tips for the DM Emulator

1. Ask questions that can be answered yes/no
2. Set reasonable odds based on the situation
3. Use random events to add twists
4. Let the chaos factor reflect how unpredictable things have become
5. Trust the results and interpret creatively
